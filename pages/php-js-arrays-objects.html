1. 配列の作り方

複数の値を順番に並べて持つときは配列を使います。インデックスはどちらも0から始まります。

PHP
$users = ['田中', '佐藤', '鈴木'];

$users[0]; // 田中
$users[] = '高橋'; //末尾に追加
JS
const users = ['田中', '佐藤', '鈴木']

users[0] // 田中
users.push('高橋') //末尾に追加

2. 連想配列とオブジェクト

名前を付けて値を管理するとき、PHPでは連想配列、JavaScriptではオブジェクトを使います。 PHPのキーは文字列でも整数でも書けます。

PHP
$user = [
    'name' => '田中',
    'age' => 30,
];

$user['name']; // 田中
$user[0]; // キーがないためエラー（インデックス的な呼び出しは不可）

$user['email'] = 'tanaka@example.com';//新しく'email'をキーにして追加
$user['0'] = '111-1111-1111';
$user[0] = '000-0000-0000';// 数値文字列 '0' は整数キー 0 として扱われ、上書きされる

JavaScriptのオブジェクトは、ドット記法とブラケット記法のどちらでも値を取得できます。 キーを変数で指定するときはブラケット記法を使います。

JS
const user = {
    name: '田中',
    age: 30,
}

user.name   // 田中
user['name'] // 田中
user.email = 'tanaka1@example.com'//新しくemailをキーにして追加
user['email'] = 'tanaka2@example.com';//ブラケット記法でも代入可能

user[name] // 変数未定義エラー　ReferenceError: name is not defined

const key = 'name'
user[key]    // 田中
user.key     // undefined

JSもオブジェクトのキーとした整数は 0 も '0' も同じ扱いになる。

JS
const user = {
    name: '田中',
    age: 30,
    0: 'テスト'
};

console.log(user[0]);   // テスト
console.log(user['0']); // テスト
目的 PHP JavaScript
順番のある複数の値 配列 配列
名前付きの値 連想配列 オブジェクト

3. 配列を繰り返し処理する

配列の各要素を処理するときは、PHPでは foreach、JavaScriptでは for...of や forEach を使います。

PHP
$users = ['田中', '佐藤', '鈴木'];

foreach ($users as $user) {
    echo $user;
}
JS
const users = ['田中', '佐藤', '鈴木']

for (const user of users) {
    console.log(user)
}

users.forEach(user => console.log(user))

4. 配列から別の配列を作る

各要素を変換するなら array_map / map、条件に合う要素だけを残すなら array_filter / filter を使います。

PHP
$numbers = [1, 2, 3, 4];

$doubled = array_map(
    fn ($number) => $number * 2,
    $numbers
);
// [2, 4, 6, 8]

$even = array_filter(
    $numbers,
    fn ($number) => $number % 2 === 0
);
// [2, 4]
JS
const numbers = [1, 2, 3, 4]

const doubled = numbers.map(number => number * 2)
// [2, 4, 6, 8]

const even = numbers.filter(number => number % 2 === 0)
// [2, 4]

5. オブジェクトの中身を調べる

オブジェクトのキーや値を一覧にすると、繰り返し処理や存在確認ができます。

PHP
$user = ['name' => '田中', 'age' => 30];

array_keys($user);   // ['name', 'age']
array_values($user); // ['田中', 30]

isset($user['email']); // false
JS
const user = { name: '田中', age: 30 }

Object.keys(user)   // ['name', 'age']
Object.values(user) // ['田中', 30]

'email' in user     // false（この例ではキーがない）
'name' in user      // true

6. 配列の中にオブジェクトを入れる

実際の画面表示では、ユーザーや商品などのオブジェクトを配列にまとめる形がよく使われます。 PHPではキーでアクセスし、JavaScriptではプロパティでアクセスします。

PHP
$users = [
    ['name' => '田中', 'age' => 30],
    ['name' => '佐藤', 'age' => 25],
];

foreach ($users as $user) {
    echo $user['name'];
}
JS
const users = [
    { name: '田中', age: 30 },
    { name: '佐藤', age: 25 },
]

users.forEach(user => console.log(user.name))

7. Vueで表示する

Vueでは、配列を v-for で繰り返し表示します。オブジェクトの値はドット記法で参照できます。 一覧の要素には、安定した識別子を :key として指定します。

Vue
<script setup>
import { ref } from 'vue'

const users = ref([
    { id: 1, name: '田中', role: '管理者' },
    { id: 2, name: '佐藤', role: '編集者' },
])
</script>

<template>
    <ul>
        <li v-for="user in users" :key="user.id">
            {{ user.name }}（{{ user.role }}）
        </li>
    </ul>
</template>
