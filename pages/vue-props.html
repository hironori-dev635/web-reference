Vue 3 + <script setup> 前提。親 → 子が props、子 → 親が emit。slot と provide/inject も「値の渡し方」。

親から子へ（props）

<!-- 親 -->
<UserCard :user="user" :active="true" title="担当" />
// 子
const props = defineProps({
    user: { type: Object, required: true },
    active: { type: Boolean, default: false },
    title: { type: String, default: '無題' },
});

props.user.name

型だけなら短縮形。

const props = defineProps<{
    user: { id: number; name: string }
    active?: boolean
    title?: string
}>()

デフォルト値は withDefaults。

const props = withDefaults(defineProps<{
    title?: string
    active?: boolean
}>(), {
    title: '無題',
    active: false,
})

子から親へ（emit）

const emit = defineEmits<{
    save: [payload: { id: number }]
    close: []
}>()

emit('save', { id: props.user.id })
emit('close')

よく使う渡し方の使い分け

手段 向き いつ
props 親 → 子 その子が使うデータ・見た目の指定
emit 子 → 親 クリック、保存、閉じるなどのイベント
v-model 双方向 入力値。詳細は「v-modelについて」
slot 親 → 子（テンプレート） ボタンや見出しなど、親側でマークアップしたいとき
provide / inject 祖先 → 孫 何段も props をリレーしたくないとき

slot

<!-- 子 -->
<header><slot name="title">デフォルト見出し</slot></header>
<div><slot /></div>
<!-- 親 -->
<UserCard :user="user">
    <template #title>{{ user.name }} さん</template>
    <p>本文はデフォルトスロット</p>
</UserCard>

子のデータを親のスロットで使うなら scoped slot。

<slot name="actions" :user="user" />

<!-- 親 -->
<template #actions="{ user }">
    <button>{{ user.id }} を編集</button>
</template>

provide / inject

// 祖先
import { provide, ref } from 'vue'
const theme = ref('dark')
provide('theme', theme)

// 孫
import { inject } from 'vue'
const theme = inject('theme', ref('light'))

忘れやすいポイント

  • props は子から書き換えない。上げたい変更は emit（または v-model）。
  • 真偽 props は <Comp active /> で true。active="false" は文字列の "false" になるので :active="false"。
  • 親が渡した属性のうち props でないものは、子のルート要素に落ちる（fallthrough）。inheritAttrs: false で止められる。
  • オブジェクトや配列を props で渡すと参照が共有される。中身を直接 mutate すると親まで変わる。
