値が null / undefined のときだけ、右側を使う。Vue も JavaScript も PHP も、書き方は同じ。

JS
a ?? b  // a が null / undefined なら b、それ以外は a
PHP
$a ?? $b  // $a が null なら $b、それ以外は $a

よくある使い方: Vue / Laravel

Vue
// デフォルト表示

<p>{{ user.name ?? 'ゲスト' }}</p>
<p>{{ user.email ?? 'メールアドレス未登録' }}</p>

<p>{{ user.profile?.nickname ?? user.name ?? '名無し' }}</p>
//nickname がある → それを使う
//nickname が null → name を使う
//name も null → 「ゲスト」を使う

<img :src="user.avatar ?? '/images/default-avatar.png'">

import { ref } from 'vue'

三項演算子との違い

null合体演算子?? は「無いとき」の逃げ。条件で A / B を切り替える用途ではない。左が true でも false でも「値はある」ので、右側は使われない。

JS
user.name.length > 10 ?? '長い'
// → true か false しか返らない（'長い' は出ない）

user.name.length > 10 ? '長い' : '短い'
// → '長い' か '短い'（こちらが正しい）
何を判定するか 用途
null合体演算子（??） 値が null / undefined か デフォルト値
三項演算子（? :） 値が真か偽か if / elseの省略
