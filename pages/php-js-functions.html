使い分けの注意

  • PHPの関数は、引数の順番がJavaScriptのメソッドと異なることがある。
  • strlen はバイト数、mb_strlen はマルチバイト文字を考慮した文字数を返す。
  • JavaScriptの typeof null は "object" になるため、null判定には value === null を使う。
  • 配列の map、filter、reduce などは、別ページの「PHPとJSの配列・オブジェクト」を参照する。
