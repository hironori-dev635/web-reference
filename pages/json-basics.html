JSON（ジェイソン）は、データを文字列としてやり取りするための軽量な形式です。 APIのリクエスト・レスポンスや設定ファイルでよく使われます。JSON自体にはコメントや変数はありません。

1. JSONの基本構文

オブジェクトは {}、配列は [] で表します。キーと文字列は必ずダブルクォートで囲み、 プロパティの間はカンマで区切ります。最後の要素にカンマは付けません。

JSON
{
  "id": 1,
  "name": "田中太郎",
  "email": "tanaka@example.com",
  "is_active": true,
  "profile": null,
  "roles": ["admin", "editor"]
}

2. JSONで使えるデータ型

型 例 ポイント
文字列 "hello" ダブルクォートで囲む
数値 42 / 3.14 クォートで囲まない
真偽値 true / false 小文字で書く
null null 値がないことを表す
オブジェクト {"name": "田中"} 名前付きのデータ
配列 [1, 2, 3] 順番のあるデータ

3. JavaScriptのオブジェクトとJSONの違い

JSONは、JavaScriptのオブジェクト記法を元に作られたデータ交換形式です。 ただし、JSONはJavaScriptそのものではなく、JavaScript以外の言語でも扱える独立したテキスト形式です。

比較 JavaScriptのオブジェクト JSON
正体 プログラム内で扱う値 データ交換用の文字列
キー { name: '田中' } のように省略できる 必ずダブルクォートで囲む
文字列 シングル・ダブルクォートのどちらも使える ダブルクォートだけ使える
その他 関数、undefined、コメントなどを扱える 関数、undefined、コメントは扱えない
JS
// JavaScriptのオブジェクト。これは文字列ではない
const user = {
  name: '田中',
  greet() {
    return `こんにちは、${this.name}さん`
  },
}

// JSON。送受信できるのは、このような文字列
const json = '{"name":"田中"}'

APIに送るときはオブジェクトをJSON文字列に変換し、受け取ったJSON文字列はオブジェクトに戻します。 この変換の境界を意識すると、「見た目が似ているのにエラーになる」理由が分かりやすくなります。

4. JavaScriptでJSONを変換する

JSON.stringify はJavaScriptの値をJSON文字列に変換し、JSON.parse はJSON文字列をJavaScriptの値に戻します。

JS
const user = {
  name: '田中',
  age: 30,
  roles: ['admin', 'editor'],
}

const json = JSON.stringify(user)
// '{"name":"田中","age":30,"roles":["admin","editor"]}'

const parsedUser = JSON.parse(json)
console.log(parsedUser.name) // 田中

人が読むために整形したいときは、JSON.stringify の第3引数にインデント幅を渡します。

JS
const formatted = JSON.stringify(user, null, 2)
console.log(formatted)

5. APIからJSONを受け取る

fetch のレスポンスは、response.json() を呼ぶとJSONをJavaScriptの値として読み取れます。 通信エラーだけでなく、HTTPステータスも確認します。

JS
const response = await fetch('/api/users')

if (!response.ok) {
  throw new Error(`HTTP ${response.status}`)
}

const users = await response.json()
console.log(users[0].name)

6. JSONを送信する

JSONをリクエストボディに入れるときは、JSON.stringify で文字列化し、 Content-Type に application/json を指定します。

JS
const user = {
  name: '田中太郎',
  email: 'tanaka@example.com',
}

const response = await fetch('/api/users', {
  method: 'POST',
  headers: {
    'Content-Type': 'application/json',
  },
  body: JSON.stringify(user),
})

7. PHPでJSONを扱う

PHPでは json_encode で配列やオブジェクトをJSONに変換し、json_decode でPHPの値に戻します。 第2引数を true にすると、デコード結果を連想配列として受け取れます。

PHP
$user = [
    'name' => '田中太郎',
    'age' => 30,
];

$json = json_encode($user, JSON_UNESCAPED_UNICODE);

$data = json_decode($json, true);
echo $data['name'];

8. LaravelでJSONレスポンスを返す

Laravelのコントローラーでは、配列を response()->json() に渡すとJSONレスポンスを返せます。 Eloquentのモデルやコレクションを渡すこともできます。

PHP
public function show(User $user)
{
    return response()->json([
        'data' => $user,
        'message' => '取得しました',
    ]);
}

9. よくある注意点

  • 文字列はシングルクォートではなく、ダブルクォートで囲む。
  • キーと値の間は :、要素同士は , で区切る。
  • 末尾のカンマ、コメント、undefined はJSONでは使えない。
  • JSONの null と、JavaScriptの undefined は別の値。
  • パスワードやトークンなどの秘密情報を、レスポンスに含めない。
JSON
// JSONではエラーになる例
{
  'name': '田中', // コメントも使えない
}
