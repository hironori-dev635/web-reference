Eloquent / Query Builder で「あのメソッド何だっけ」用。生 SQL に近い順ではなく、よく叩く順。

取得

メソッド 意味
get() 複数行。Collection が返る
first() / firstOrFail() 1件。無ければ null / 例外
find($id) / findOrFail($id) 主キーで1件
value('email') 先頭行の1カラムだけ
pluck('name', 'id') 値の配列。第2引数はキー
count() / exists() / doesntExist() 件数・存在確認。全件 get しない
paginate(20) / simplePaginate(20) ページネーション
toSql() 実行せず SQL 文字列だけ見る 
User::query()
    ->where('active', true)
    ->orderBy('id')
    ->toSql();

WHERE

メソッド 例
where ->where('status', 'open') / ->where('age', '>=', 18)
orWhere ->where('a', 1)->orWhere('b', 2)
whereIn / whereNotIn ->whereIn('id', [1, 2, 3])
whereNull / whereNotNull ->whereNull('deleted_at')
whereBetween ->whereBetween('price', [100, 500])
whereDate / whereYear ->whereDate('created_at', '2026-08-16')
whereColumn ->whereColumn('updated_at', '>', 'created_at')
whereHas リレーション先の条件。->whereHas('posts', fn ($q) => $q->where('pub', true))
グループ ->where(fn ($q) => $q->where('a', 1)->orWhere('b', 2))

SELECT / JOIN / 並び

メソッド 例
select / addSelect ->select('id', 'name')
selectRaw ->selectRaw('count(*) as c')
distinct ->distinct()->pluck('city')
join / leftJoin ->leftJoin('profiles as p', 'p.user_id', '=', 'users.id')
orderBy / latest ->orderBy('name') / ->latest()（created_at desc）
groupBy / having ->groupBy('user_id')->having('c', '>', 1)
limit / offset ->limit(10)->offset(20)。別名 take / skip

更新系

メソッド 例
insert DB::table('x')->insert(['name' => 'a'])
insertGetId 入れて主キーを返す
update User::where('id', 1)->update(['name' => 'a'])
upsert ->upsert($rows, ['email'], ['name'])（一意キー, 更新カラム）
increment / decrement ->increment('login_count')
delete ->where('id', 1)->delete()

忘れやすいポイント

  • N+1 は with('posts')。あとから足すなら load('posts')。
  • 大量行は chunk(100, fn ($rows) => ...) か cursor()。
  • 生の断片は whereRaw / selectRaw / DB::raw。バインドを忘れない。
  • Eloquent の User::where(...) は内部で Query Builder。迷ったら User::query()-> から書き始める。
