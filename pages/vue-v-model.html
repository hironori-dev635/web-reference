Vue 3 の v-model は「値を渡す + 更新イベントを受け取る」の糖衣。コンポーネントに載せるときは defineModel() が一番短い。

素の input

<input v-model="name" />

これはだいたい次と同じ。

<input :value="name" @input="name = $event.target.value" />
修飾子 意味
v-model.lazy input ではなく change（フォーカスが外れたとき）
v-model.number 文字列ではなく数値として入れる
v-model.trim 前後空白を落とす 
<input v-model.trim.number="age" />
<input type="checkbox" v-model="ok" />
<select v-model="city">...</select>

コンポーネントで使う（defineModel）

<!-- 親 -->
<PriceInput v-model="price" />
// 子 PriceInput.vue
const price = defineModel({ type: Number, default: 0 })

<input type="number" v-model="price" />

defineModel() は props の modelValue と emit の update:modelValue をまとめて作る。

名前付き v-model（複数）

<!-- 親 -->
<UserForm v-model:name="name" v-model:email="email" />
// 子
const name = defineModel('name')
const email = defineModel('email')

名前を省略した v-model="x" だけが modelValue。v-model:title="x" は prop 名 title + イベント update:title。

defineModel より前の書き方

古い資料に出てくる形。中身は同じ。

const props = defineProps({ modelValue: String })
const emit = defineEmits(['update:modelValue'])

function onInput(e) {
    emit('update:modelValue', e.target.value)
}
<input :value="modelValue" @input="onInput" />

チェックボックス・オブジェクト

const picked = defineModel({ type: Array, default: () => [] })

<input type="checkbox" value="php" v-model="picked" />
<input type="checkbox" value="js" v-model="picked" />

親の picked が ['php', 'js'] のように更新される。

忘れやすいポイント

  • Vue 2 は子の prop 名が value、イベントが input。Vue 3 は modelValue / update:modelValue。
  • defineModel() の戻り値は ref。テンプレートでは自動アンラップ、script では price.value。
  • オブジェクトを v-model すると参照が共有されやすい。ネストを子で直接いじると親の state が黙って変わる。
  • 修飾子を子で受け取るなら defineModel({ local: true }) ではなく、const [model, modifiers] = defineModel() の第2戻り値を見る。
