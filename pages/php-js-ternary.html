if / else を1行で書いたもの。Vue も JavaScript も PHP も、書き方は同じ。

JS
a ? b : c  // aがtrueならb、falseならc
PHP
$a ? $b : $c  // aがtrueならb、falseならc

ifを使った場合との比較

JS
let ok="OK";

// 三項演算子
ok ? '公開' : '下書き'

// 同じ意味の if
if (ok) {
    return '公開'
} else {
    return '下書き'
}
php
$ok="OK";

// 三項演算子
$ok ? '公開' : '下書き'

// 同じ意味の if
if ($ok) {
    return '公開'
} else {
    return '下書き'
}

よくある使い方: Vue / Laravel

Vue
// 文字の表示切替
<span>{{ user.is_admin ? '管理者' : '一般ユーザー' }}</span>

// クラスの切替
<div :class="isActive ? 'bg-blue-500' : 'bg-gray-300'">
    {{ user.name }}
</div>

// ボタン文言（送信中）
<button>{{ saving ? '保存中...' : '保存' }}</button>

// 属性の切替
<button :disabled="saving ? true : false">  // 遠回り
<button :disabled="saving">                 // 同じ意味

// 画像のフォールバック
<img :src="user.avatar ? user.avatar : '/default.png'">

// 件数。0 のときはハイフン
{{ count > 0 ? count + '件' : '-' }}

// style の切替
<p :style="{ color: ok ? 'green' : 'red' }">
blade
// 文字の表示切替
<span>{{ $user->is_admin ? '管理者' : '一般ユーザー' }}</span>

// クラスの切替
<div class="{{ $isActive ? 'text-blue-500' : 'text-gray-500' }}">
    {{ $user->name }}
</div>

// ボタン文言（送信中）
<button>{{ $saving ? '保存中...' : '保存' }}</button>

// selected / checked / disabled（古い書き方）
<option value="1" {{ $status === 1 ? 'selected' : '' }}>
<input type="checkbox" {{ $ok ? 'checked' : '' }}>
<button {{ $saving ? 'disabled' : '' }}>

// 同じことを Blade ディレクティブで（こちらのほうが読みやすい）
<option value="1" @selected($status === 1)>
<input type="checkbox" @checked($ok)>
<button @disabled($saving)>

// 画像のフォールバック
<img src="{{ $user->avatar ? $user->avatar : '/default.png' }}">

// 日付があるときだけ整形
{{ $post->published_at ? $post->published_at->format('Y/m/d') : '未公開' }}

// リンク先の切替
<a href="{{ $user->is_admin ? route('admin.home') : route('home') }}">

条件の判定の違い（何がfalseになるか）

値 JS PHP
""（空文字） false false
"0"（文字のゼロ） true false
0 false false
0.0 false false
false false false
null false false
[]（空配列） true false
オブジェクト（JSでは{}　PHPではnew stdClass() ） true true
undefined false なし
NaN false true

現場で事故りやすいのは "0" と []。JS / Vue では true、PHP では false。
