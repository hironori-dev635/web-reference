1. 基本的な関数定義

関数の定義、呼び出しはPHPとJSで基本的には同じです。

Vue
<script setup>
function greet(name, count) {
    return `${name}さん、${count}件`
}
</script>

<template>
    <p>{{ greet(user.name, 3) }}</p>
</template>

JavaScript はセミコロンを省略できますが、次の行が (、[、テンプレートリテラル`string text ${expression} string text`などで始まると、前の行と意図せずつながることがあります。省略する場合も、文の先頭にセミコロンが必要になる書き方を避けるなど、ASI（自動セミコロン挿入）に依存しすぎない注意が必要です。

php
// 関数定義（Laravelでは helper や Controller）
function greet($name, $count)
{
    return $name . 'さん、' . $count . '件';
}

$g = greet($user->name, 3);

// Blade では呼ぶだけ
{{ greet($user->name, 3) }}

2. デフォルト引数

デフォルト引数は、引数を省略したときにだけ使われます。null を明示的に渡してもデフォルト値には置き換わりません。

PHP
function greet($name = 'ゲスト', $count = 0)
{
    return $name . 'さん、' . $count . '件';
}

greet();            // ゲストさん、0件
greet('田中');      // 田中さん、0件
greet('田中', 3);   // 田中さん、3件
greet(null);        // さん、0件（$name は nullなので）
JS
function greet(name = 'ゲスト', count = 0) {
    return `${name}さん、${count}件`
}

greet()             // ゲストさん、0件
greet('田中')       // 田中さん、0件
greet('田中', 3)    // 田中さん、3件
greet(null)         // さん、0件（name は null）

user = {
    name: '田中'
}
greet(user.name)    // 田中さん、0件
greet(user.kana)    // ゲストさん、0件（ kana は存在しないので undefined）

3. 型指定

PHPの型指定

PHPでは、関数の引数や戻り値に型を指定できます。

PHP
function greet(string $name = 'ゲスト', int $count = 0): string
{
    return $name . 'さん、' . $count . '件';
}

string、int、array などの基本的な型だけでなく、クラス名を指定して、そのクラスのオブジェクトを受け取ることもできます。 Laravelでは、Request、Model、Collection、Serviceクラスなどを型として指定する機会が多くあります。

→ Laravelでよく使う型指定を見る



JavaScriptの型指定

JavaScriptは関数の引数や戻り値にPHPのような型宣言を基本的に書きません。

JS
function greet(name, count) {
    return `${name}さん、${count}件`;
}

一方、TypeScriptではJavaScriptに型指定を追加できます。

JS
function greet(name: string, count: number): string {
    return `${name}さん、${count}件`;
}
→ TypeScriptの型指定を見る

4. null許容

JS
function getNames(users) {
    if (!users) {
        return [];
    }

    return users.map(user => user.name);
}
getNames(null);       // []
getNames(undefined);  // []
getNames([]);         // []
getNames([{ name: '田中' },{ name: '佐藤' }]);    // ['田中', '佐藤']

JavaScript には型指定がないため、null を渡せますが、関数内の処理でnullでエラーになることがあり、対策が必要な場合があります。引数の型を静的に検査したい場合は TypeScript を使います。


PHP
function greet(?string $name)
{
    return $name ?? 'ゲスト';
}

greet('田中');  // 田中
greet(null);    // ゲスト
greet();        // エラー（引数がない）

// 省略も許可するならデフォルトも付ける
function greet(?string $name = 'ゲスト') 
{ return $name ?? 'ゲスト'; }

greet()         // ゲスト（デフォルトが入る）
greet(null);    // ゲスト（NULLガードが入る）

PHP では、型付き引数は原則として null を受け付けず、型エラーになります。
null を許可する場合は、型の前に ? を付けます。

5. 可変長引数

可変長引数は、いくつの引数を受け取るか決まっていない関数で使います。引数の前に ... を付けると、渡された複数の値をまとめて配列として受け取れます。

PHPの可変長引数

PHP
function total(int ...$numbers): int
{
    return array_sum($numbers);
}

total(1, 2);       // 3
total(1, 2, 3, 4); // 10

PHPでは、可変長引数 ...$numbers は関数の中で配列になります。型を付けると、 受け取る値の型も指定できます。

JavaScriptのレストパラメータ

JS
function total(...numbers) {
    return numbers.reduce((sum, number) => sum + number, 0)
}

total(1, 2);       // 3
total(1, 2, 3, 4); // 10

JavaScriptでは、可変長で受け取る引数をレストパラメータと呼びます。PHPと 同じく、関数の中では配列として扱えます。通常の引数と組み合わせる場合は、レストパラメータを最後に書きます。

JS
function greet(prefix, ...names) {
    return names.map(name => `${prefix}、${name}`)
}

greet('こんにちは', '田中', '佐藤')
// ['こんにちは、田中', 'こんにちは、佐藤']

Vueでの利用例

Vue
<script setup>
function joinNames(...names) {
    return names.join('、')
}

const result = joinNames('田中', '佐藤', '鈴木')
</script>

<template>
    <p>{{ result }}</p>
</template>

なお、関数に配列を渡して、その要素を個別の引数として展開したい場合も ... を使います。受け取るときはレストパラメータ、渡すときはスプレッド構文です。

JS
function total(...numbers) {
    return numbers.reduce((sum, number) => sum + number, 0)
}

const numbers = [1, 2, 3]
total(...numbers) // 6

6. 無名関数

無名関数は、関数そのものに名前を付けずに作る関数です。変数に代入してあとから呼び出すことも、map などの引数に直接渡すこともできます。 アロー関数は、無名関数をより短く書く方法の一つです（7）。

変数に代入して呼び出す

JS
const greet = function (name) {
    return `こんにちは、${name}`
}
  greet('田中');
PHP
$greet = function ($name) {
    return 'こんにちは、' . $name;
};
  $greet('田中');

関数を引数として直接渡す場合は、変数に代入せずその場で書けます。

JS
const doubled = [1, 2, 3].map(function (n) {
    return n * 2
})
// [2, 4, 6]
PHP
$doubled = array_map(function ($n) {
    return $n * 2;
}, [1, 2, 3]);
// [2, 4, 6]

外側の変数を使う場合、JavaScript は同じスコープの変数をそのまま参照できます。PHP の無名関数は、外側の変数を使うときに use で明示します。

JS
const label = '件'
const format = function (count) {
    return count + label
}

format(3) // 3件
PHP
$label = '件';
$format = function ($count) use ($label) {
    return $count . $label;
};

$format(3); // 3件

7. アロー関数

アロー関数は、無名関数を短く書くための JavaScript の構文です。=> の左側に引数、右側に処理を書きます。関数を一度だけ渡す map や filter などでよく使います。

基本構文

JS
const greet = (name) => {
    return `こんにちは、${name}`
}

greet('田中') // こんにちは、田中

処理が1行だけの場合は、波かっこと return を省略できます。この書き方を 暗黙の戻り値といいます。引数が1つだけなら、引数の丸括弧も省略できます。

JS
const double = n => n * 2
const doubled = [1, 2, 3].map(n => n * 2)

// [2, 4, 6]
console.log(doubled)

オブジェクトを暗黙に返す場合は、オブジェクト全体を丸括弧で囲みます。丸括弧がないと、 {} は関数の処理ブロックとして解釈されます。

JS
const toUser = name => ({
    name: name,
    active: true
})

toUser('田中') // { name: '田中', active: true }

外側の変数は、無名関数と同じようにそのまま参照できます。Vue の computed や配列操作でも、この形がよく使われます。

Vue
<script setup>
import { computed, ref } from 'vue'

const count = ref(3)
const message = computed(() => `${count.value}件`)
</script>

<template>
    <p>{{ message }}</p>
</template>

アロー関数は通常の関数と違い、独自の this を持ちません。外側の this をそのまま使うため、オブジェクトのメソッドなどで this をそのオブジェクト自身にしたい場合は、通常の関数を使います。

PHPのアロー関数

PHPにも短い関数を書くためのアロー関数があります。PHPでは fn と書き、 式の結果が自動的に戻り値になります。外側の変数は自動的に値で取り込まれます。

PHP
$tax = 0.1;
$prices = [100, 200, 300];

$withTax = array_map(
    fn ($price) => $price * (1 + $tax),
    $prices
);

// [110, 220, 330]

JavaScriptのアロー関数とPHPのアロー関数は似ていますが、構文は別物です。複数の文を 実行したい場合や、複雑な処理を書く場合は、通常の関数のほうが読みやすくなります。
